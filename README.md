# RowdyQL

סביבת לימוד אינטראקטיבית לקורס "תכנון בסיסי נתונים" (אוניברסיטת אריאל, הנדסת תעשייה וניהול).
מבוא לעולם ה-SQL, אלגברה רלציונית עם ממחישים, תרגילים ובחינה עצמית. עברית ואנגלית.

- `src/page.html` — מקור הדף (גוף בלבד, בלי html/head/body).
- `build.py` — עוטף את המקור ל-`index.html` העצמאי שמוגש ב-GitHub Pages.
- `index.html` — הקובץ שמוגש. לא לערוך ידנית; לערוך את המקור ולהריץ `python build.py`.
- `raz-elbaz-brand-identity-kit/voice/` — הקול הרשמי של האתר: `raz-elbaz-brand-identity-kit/voice/voice-profile.md` (עברית) ו-`raz-elbaz-brand-identity-kit/voice/voice-profile-en.md` (אנגלית). `build.py` מריץ את בדיקת הקול ועוצר על הפרה חדשה.

## שיעורים

- **אתר אחד:** RowdyQL הוא אתר ציבורי אחד, בלי מהדורות ובלי אזכור של מוסד או ארגון. השאלות בהרשמה על מוסד הלימודים, שנה וסמסטר נשארות בכוונה, כי רז אוסף את המידע הזה.
- **מחרוזות:** כל הטקסטים יושבים ב-`I18N`, בעברית ובאנגלית.
- **שיעורים:** `COURSE` מחלק כל פרק (יחידה) לשיעורים של 15 עד 20 דקות: `{ id, secs, min }`, והכותרת במפתח `ls_<id>`. תוכן חדש נבנה ישר כשיעורים.
- **צוות:** חשבון עם `role = 'teacher'` בטבלת הפרופילים רואה את לוח הניהול (נרשמים, התקדמות, ייצוא), את הערות ההוראה בשיעורים ואת מצב המצגת.
